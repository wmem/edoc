# 布局约束使用与验收

2026-11-01。用户批准“默认可用、按需声明、局部覆盖、明确校验”的工具方向后，本批先实现图形布局意图和默认路由修复。全工具原则见[声明式展示与约束设计](声明式展示与约束设计.md)；本文是当前字段契约与验收范围，不代表表格、时序、主题和发布设置已一并实现。

## 使用入口

使用新属性的 IR 建议写入 `irVersion: "1.2"`，并在 manifest.requiredFeatures 声明 `layout-intent`。使用接口分组时继续同时声明 `interface-groups`。不声明必需能力会报错，旧读取器不能静默忽略必须理解的布局意图；没有新属性的旧工程继续沿用原有协议。

新属性位于 View.layout，引用原始稳定 ID，工程对象和 Connection.endpoints 不变。不填写新属性时工具仍负责默认布局、可追踪端点与可读标题；普通图不要求手写坐标。

| 属性 | 内容 | 性质与边界 |
| --- | --- | --- |
| constraints | order 或 align 数组，每项有 axis 和 nodes | 必须满足；节点必须在视图范围内，且属于同一父容器；顶层节点可共同约束 |
| order | nodes 沿 x 或 y 正方向依次排列 | 按边框保证最小间距；倒序表达反向排列 |
| order.gap | 最小间距，默认 80，最小 16 | 单位为 Scene 逻辑像素；工具可为标题和避障增加间距，不承诺精确等于 gap |
| align | nodes 的中心在 x 或 y 轴坐标上对齐 | align.x 表示垂直对齐，align.y 表示水平对齐；沿用各节点实际尺寸 |
| relationHints[原关系 ID].backbone | 同一原关系中的两个不同端点 ID | 优先作为显示主干；其他端点仍接入原 Net，不表示真实 PCB 走线 |
| relationHints[原关系 ID].endpointSides | Node 端点 ID 到 left/right/top/bottom 的映射 | 必须遵循的显示出入侧边；不生成工程 Port，不覆盖真实 Port 的侧边 |
| relationHints[原关系 ID].channel | left/right/top/bottom | 两端点关系的外侧通道偏好；不可行时可放宽并报告，不用于多端点 Net |
| relationHints[原关系 ID].priority | main 或 normal，默认 normal | main 优先布线和协调标题；不改变关系类别、方向或电气优先级 |

已有 direction、routing、portOrder、positions、interfaceOrder、interfaceSides 继续使用。固定位置与新约束冲突时明确失败；最终画布可能为标题/留白整体平移，不能把 Scene 逻辑坐标直接当作屏幕坐标。

## 示例

相对位置与对齐只涉及本层节点；需要跨层组织时先调整容器，再调整其子节点。没有任意跨层中心对齐或作者指定折点的公开字段。

```json
{
  "layout": {
    "direction": "LR",
    "constraints": [
      {"type": "order", "axis": "x", "nodes": ["mac:control", "mac:data-plane"], "gap": 140},
      {"type": "order", "axis": "y", "nodes": ["mac:tx", "mac:rx"], "gap": 100},
      {"type": "order", "axis": "x", "nodes": ["mac:rx", "mac:fifo"], "gap": 220},
      {"type": "align", "axis": "x", "nodes": ["mac:tx", "mac:rx"]},
      {"type": "align", "axis": "y", "nodes": ["mac:rx", "mac:fifo"]}
    ],
    "relationHints": {
      "mac:rel.rxfifo": {"priority": "main", "endpointSides": {"mac:rx": "right", "mac:fifo": "left"}},
      "mac:rel.event": {"channel": "bottom"}
    }
  }
}
```

多端点关系只补充主干选择，无须重新列出第三端点或维护分叉坐标：

```json
{
  "layout": {
    "relationHints": {
      "board:net.FLASH_SCK": {"backbone": ["board:U1.QSPI_CLK", "board:U5.CLK"]}
    }
  }
}
```

完整可运行示例为 [constraints.json](../examples/gallery/constraints.json)。运行 `npm run demo` 后打开“按需声明布局意图”，与默认架构/接线图对照；`npm run demo:build` 生成相同 HTML、SVG 和 PDF。

## 校验、覆盖与接口投影

- validate 检查字段类型、能力协商、引用、视图范围、兄弟节点作用域，以及 order/align 的循环矛盾；启用 layout-intent 后，布局字段拼写错误不按兼容 minor 字段静默忽略。
- 涉及实际尺寸、固定位置、节点重叠和可用通道的约束在 Scene/build/export 时校验。不能把 validate 成功解释成版面已经验收。冲突报告包含视图/对象及配置来源。
- 通道偏好放宽或为标题重新安排通路时，警告保存在 SceneNet.layoutWarnings，HTML 图旁或接口状态区显示说明，SVG metadata 保留说明。没有合法路径时仍然失败，不能用警告代替基本正确性。
- 有专属 relationHints 的原关系保持独立显示线，避免被其他关系的接口聚合吞掉。没有专属提示的关系继续按已有规则聚合；这是保留局部意图的明确取舍，可能增加少量显示线。
- 接口展开/折叠时，backbone 根据原 Port ID 投影到对应接口或槽位；两端折叠到同一接口时暂时不使用该主干提示并说明原因，展开后恢复。提示不要求作者引用临时显示 ID。
- 本批仅实现 View 中的局部设置。项目展示默认、正文引用处覆盖、全工具有效配置查询、可保存的网页布局编辑尚未实现，不能按规划中的覆盖链编写当前配置。

## 默认路由修复

本批修复[二次审查](图形约束二次审查.md)指出的问题，而非依赖作者填写新属性来回避缺陷：

1. 无真实端口的模块按关系分配独立锚点和出线走廊；节点高度随关系数量保留必要空间。真实 Port 仍精确挂接。
2. 回退路由禁止不同关系长距离共线，避开其他关系的折角/终端，直线内部交叉仍可存在。共享真实 Port 是有数据依据的连接，不能误判成假接触。
3. 所有关系先求路径，再协调线上标题；同时预留其他端口走廊，防止先放的标签堵住内部回路或后续关系。标题避开父容器边框与实际分叉，容器增加内部留白。
4. 多端点使用主干与支路组成实际渲染树，不再让虚拟 hub 增加额外布局层。联合线段去重，按实际 degree>=3 的分叉绘制圆点，可有多个 T 点。
5. Scene 保留全部端点及其到树的路径，同时提供去重的绘制 paths 与真实 junctions。网页、SVG、PDF 消费同一份几何；SVG 起点/终点箭头按实际路径方向绘制。

这不是任意规模、任意密度图的全自动质量保证。精确固定位置下空间不足时仍需增加间距、缩短显示标题或拆出范围明确的详图，完整工程事实继续可查。

## 验证入口与范围

- `npm run test:layout`：原 MAC 无新提示的锚点/共线/接触/父框标签；多端点真实分叉和共享段去重；相对约束、主干、反馈、无效输入、冲突、接口状态投影及四端点多 T 点。
- `npm run test:graph`、`npm run test:interface`、`npm run test:quality`：已有四方向、固定障碍、短通道标题、内部关系、展开组合和完整来源回归。
- [constraints.playwright.js](../examples/gallery/constraints.playwright.js)：用 playwright-cli/已有 Chromium 检查默认与带提示的四张图，比较 X6、SVG 与共享几何，检查真实分叉、相对布局、反馈、查询、下载、打印和窄屏。
- Demo 的完整交互、离线、文字开关和波形分别使用 gallery 下已有检查脚本；PDF 另外检查实际页面与书签，不能以浏览器打印截图替代 PDF 验收。

- Demo PDF 为 26 页、22 项递归书签；检查新增章节父子路径、全部布局 Tabs、接口信号与波形文本。视觉抽检第 21 页架构与第 22 页主干接线，标题、路径、分支和节点完整；未逐页人工审阅全部 PDF。
- 用本工具读取 KY3134 独立工程现有 IR，45 视图（26 张带线）均可生成 Scene；检查未检出路径穿实体节点、标题覆盖实体节点/其他标题、其他关系穿标题。此项是当前工具对真实 IR 的只读几何检查，本批未修改该工程依赖、原始数据或发布物，也不等于该工程已完成逐图浏览器/视觉验收。
