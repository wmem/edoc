## 正文精确读取

新增 engdoc read 与核心 readDocument API，保留原 query 的工程事实契约：

```sh
engdoc outline --format json
engdoc read --id ref:config-data --format json
engdoc read --id ref:config --scope subtree --max-chars 4000 --offset 0
engdoc query --id board:net.FLASH_SCK --depth 1
```

outline 增加源 sectionId，HTML 编码锚点继续保留。read 默认 self 排除子 section 正文，显式 subtree 才包含；返回规范化 Markdown、来源、子章节与字符范围。默认正文上限 12000 Unicode 字符，明确 truncated/nextOffset，不在返回中展开 HTML、图形、字体或 PDF。include 保留自身来源，sources 按文件汇总首次位置，不重复列出每个段落。

实际 ref:config-data 的正文为 613 个 Unicode 字符，紧凑 JSON 约 1.6 KiB；当前完整 HTML 约 12 MiB。该对照说明不必读整份发布物，不能据此承诺固定 token 节省比例。CLI 每次仍加载和校验当前组合，没有引入常驻服务、持久查询缓存或文件内容 hash。

## 迁入时发现并修复的通用问题

Markdoc 默认处理代码围栏内标签，导致教程里的 include 样例触发文件读取，diagram/section 样例也可能被误计入依赖和索引。现在围栏按字面内容展示，先排除其解析子树再校验/扫描，渲染保留原代码文本。实际围栏中的缺失路径和伪 ID 不再形成工程输入；围栏外的真实引用继续严格校验。

视觉检查还发现默认展开所有文章小节使目录过密。侧栏现先收起未阅读文章的细节，进入文章时打开对应路径；只标记当前定位项，避免整篇所有小节都呈现选中状态。本页目录继续保留。
