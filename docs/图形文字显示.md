# 图形文字显示

2026-11-01，用户批准将图上的端口名称与属性附注分开，默认隐藏附注、按需恢复；同时要求连线标题落在对应线上，并能单独隐藏。本次调整只改变显示，不删除工程事实、端口、分支、来源或查询能力。

## 行为与使用

- 端口名称和连接位置始终保留；“端口属性”开关显示/隐藏方向、位宽、时钟域和视图选定的 Ball/Pin 等扩展字段。默认关闭，详细接口可通过 `view.display.showPortAttributes: true` 初始展开。
- 连线标题默认在线段上显示，用背景留白隔开文字与本关系；“连线标题”开关只隐藏名称，不隐藏线。`view.display.showRelationLabels: false` 可改变初始状态。
- 两个开关逐图独立，切换不重新布局，不改变连线归属；不把同一多端点关系拆成独立 Net。分类切换和分组展开不会意外恢复被关闭的标题。
- 扩展字段仍由 `display.portAttributes` 选择。`function` 与端口名称完全相同时，附注省略重复功能名，原始属性和对象面板保留原值。
- 构建 HTML、CLI SVG 与 PDF 使用相同的视图初始设置。网页 SVG 下载与浏览器打印跟随当前图的文字开关；已生成的 PDF 保持构建时状态。文字开关不改变既有分类筛选/分组的完整视图静态导出约定。
- 刷新恢复视图初始状态，不写回 IR 或项目源。静态 SVG 保留隐藏文字和完整来源 metadata，隐藏不等于删除。

详细接口原本需要展示方向、位宽、时钟域；本次经用户批准，交互图默认改为简洁名称。这些信息仍可以一键展开，并可由作者设置详细初始状态，未降低逐端口完整性或事实准确要求。

配置示例见 [V1 开发与使用](V1-开发与使用.md#图形文字显示)，组织建议见[推荐指南](推荐指南.md)。

## 排版实现与边界

自动布局使用 ELK 的 inline edge label，在线段上预留文字空间，再按实际路径定位标题并检查节点、其他标题、其他关系路径。固定位置/层级回退直接在线段上寻找无碰撞位置；通道太短时保持节点与真实端口不动，将同一关系绕过空白区域，为标题增加足够长的线段。不会把找不到位置的标题丢到不相干的空白处。长标题可换行，优先使用足够长的线段；仍无可读空间时明确报错，作者需增加间距或拆分视图。

两端点关系在求标签位置时恢复完整路径，不能将内部渲染用的中点当作真实拐点或限制文字宽度。多端点仍保留共同分叉和全部端点。X6、静态 SVG 与 PDF 消费同一 Scene 几何，文字开关不改变几何。

交互检查还发现原有连线的透明命中区域覆盖端口圆点。现在完整关系路径绘制在普通节点下方，标题在上方，层级包围框在最底层，使端口可以直接点击；没有通过强制触发点击来绕过问题。

当前不支持拖动单个标题、逐条关系的界面开关、旋转文字或网页设置持久化。分组总览的聚合线沿用其现有绘图库标签；完整展开的关系标题使用共用的线上几何。

## 验证入口

- `npm run test:graph`：四方向扇出、固定障碍、反向/平行关系、长中文标题、多端点和循环关系；检查标题落在所属线上、不遮断其他关系，显示配置不改变节点/关系事实。
- `npm run test:schema`：两个显示配置仅接受布尔值，与字段列表分别校验。
- `npm run test:browser`：已有离线回归增加附注显隐、分类/分组与标题开关组合、属性查询、SVG 下载与打印检查。
- `examples/gallery/display.playwright.js`：通过 playwright-cli 在实际 Demo 检查两个开关、逐图隔离、线上几何、属性查询、下载与打印，并保存三种显示状态的截图。完整 Demo 的交互/几何、离线与波形另用原有检查脚本。

这些检查覆盖指定样例，不代表任意密度的图都能自动排版；PDF 仍需视觉核对代表页。
